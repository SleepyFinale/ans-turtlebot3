# Turtlebot3 Scripts Layout

This repository groups scripts by purpose, similar to the central-computer repo:

- `scripts/build/` - workspace rebuild helpers.
- `scripts/env/` - ROS environment/profile utilities and runtime helpers.
- `scripts/network/` - Wi-Fi switching and boot-time connectivity setup.
- `scripts/diagnostics/` - robot-side debug capture, analyzers, and health checks.
- `scripts/monitor/` - runtime bottleneck monitoring utilities.
- `scripts/security/` - SNS security/auth/bridge scripts.
- `scripts/tools/` - standalone helper tools.

Use paths from these folders in docs and operator runbooks to keep references consistent.
